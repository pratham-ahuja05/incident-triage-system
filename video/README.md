# Incident Triage — promo video

A 75-second, 1080p ad built in code with [Remotion](https://www.remotion.dev/). Title cards, the animated
pipeline, the architecture diagram and the outro are generated; your screen recordings slot in between.

```bash
cd video
npm install
npm run studio          # live preview in the browser, scrub the timeline
npm run render          # → out/incident-triage-ad.mp4
npm run render:vertical # → 9:16 version for Reels / Shorts
```

## Adding your recordings

1. Seed realistic data first: `python demo_seed.py --archive-existing` (project root; see its docstring).
2. Record each shot (OBS, Cap or FocuSee) at 1920×1080, dark theme, browser zoom 110–125%, bookmarks bar hidden.
3. Save them in `public/recordings/` (e.g. `investigation.mp4`).
4. Set the file names in `src/config.js` → `CLIPS`. Until a file is set, that scene shows a labelled placeholder.
5. Music: `public/music.m4a` is an original score generated by `scripts/make_music.py` (suspense → relief, timed to the scenes). Re-run it after changing scene lengths.

Your name, GitHub link and stack chips are also in `src/config.js`.
